# Raider LogicLab

The discipline of logic and argument for Regis Jesuit students: from deductive to inductive reasoning, valid and sound arguments, if-then reasoning, Aristotle’s A-E-I-O statements, the square of opposition and syllogisms, sampling, correlation and cause, the limits of induction, inference to the best explanation, the fallacies, and steelmanning. Part of the Raider Labs suite.

**Live site:** https://rjedtech.github.io/Raider-LogicLab/

## How each lesson works
1. **Start here:** an original joke that is a logic mistake on purpose, what it shows, and a real case where the same idea mattered (with sources).
2. **Learn it:** a picture that changes with every step (Back / Next), with “What you see” and “Why.”
3. **Try it:** hands-on practice (counterexample hunt, Venn shading, syllogism machine, truth-table switches, a pretend-school survey, the 2-4-6 game, mysteries, fallacy cases).
4. **Why it matters:** where students meet it, a success story, and where logic meets philosophy and theology.
5. **Test yourself:** one question at a time, help first, Copy for Canvas.

**Fallacy Detective** (`detective.html`) mixes 22 fallacies with fair arguments that only look like fallacies.

## Files
`index.html`, `lesson.html`, `detective.html` (shared header, menu and footer), `logic.js` (lesson engine), `tools.js` (Try it tools), `fallacies.js` (fallacies and cases), `units.js` (units and class paths), `lessons/*.js` (one file per lesson), `kit/` (Raider Labs Lesson Kit: read aloud, easier reading, “This confused me,” Test yourself). Everything runs in the browser; no student data leaves the device. GoatCounter counts anonymous page views.

The syllogism checker was tested on all 256 syllogism forms and finds exactly the 15 that are valid in every case.
